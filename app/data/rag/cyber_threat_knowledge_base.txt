================================================================================
CATEGORY: SOCIAL ENGINEERING ATTACKS
DESCRIPTION:
Social engineering attacks exploit human psychology rather than technical vulnerabilities.
They manipulate users into revealing confidential information or performing harmful actions.
================================================================================

--------------------------------------------------------------------------------
THREAT NAME: PHISHING
CATEGORY: SOCIAL ENGINEERING

Definition:
Phishing is a deceptive attack technique in which an adversary impersonates a trusted entity
to trick victims into revealing sensitive information such as login credentials, financial data,
or personal identification details.

Attack Mechanism:
Attackers typically distribute fraudulent emails, messages, or websites that mimic legitimate
organizations. Victims are persuaded to click malicious links, download attachments, or enter
credentials into fake portals.

Technical Indicators:
- Suspicious sender domain variations
- Mismatched URLs
- Urgent or threatening language
- Unexpected attachments
- Spoofed branding elements

Common Payloads:
- Credential harvesting pages
- Malware download links
- Malicious PDF/Office attachments
- Fake login portals

Detection Methods:
- Email header analysis
- URL reputation analysis
- Domain similarity detection
- User behavior anomaly monitoring
- Secure email gateways

Severity Factors:
- Number of targeted users
- Sensitivity of requested data
- Organizational privilege level of victims
- Presence of malware payload

Risk Level Logic:
Risk increases when phishing targets high-privilege accounts, financial systems,
or critical infrastructure environments.

MITRE ATT&CK Mapping:
- Initial Access (T1566)
- Credential Access
- Execution (if malware delivered)

Real-World Impact:
Phishing remains one of the most prevalent initial access vectors for ransomware,
business email compromise (BEC), and data breaches worldwide.

Keywords:
email spoofing, credential harvesting, fake login, social manipulation,
deceptive communication, malicious link
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
THREAT NAME: SPEAR PHISHING
CATEGORY: SOCIAL ENGINEERING

Definition:
Spear phishing is a targeted phishing attack directed at a specific individual,
organization, or role, using personalized information to increase credibility.

Attack Mechanism:
Attackers gather intelligence about the victim (job role, colleagues, suppliers,
recent activities) and craft customized messages that appear legitimate and relevant.

Technical Indicators:
- Highly personalized content
- Spoofed internal email addresses
- Impersonation of executives or partners
- Context-aware messaging
- Target-specific malicious attachments

Common Payloads:
- Malware-laced documents
- Credential harvesting portals
- Business email compromise setups
- Remote access trojans (RATs)

Detection Methods:
- Behavioral anomaly detection
- Email authentication validation (SPF, DKIM, DMARC)
- Advanced threat intelligence correlation
- Endpoint detection and response (EDR)

Severity Factors:
- Executive-level targeting
- Financial authorization access
- Access to confidential databases
- Lateral movement potential

Risk Level Logic:
Risk is significantly higher than generic phishing due to personalization,
higher success rate, and targeted privilege exploitation.

MITRE ATT&CK Mapping:
- Initial Access (T1566.002)
- Credential Access
- Lateral Movement

Real-World Impact:
Frequently used in corporate espionage, ransomware deployment,
and large-scale financial fraud operations.

Keywords:
targeted phishing, executive impersonation, business email compromise,
personalized attack, credential theft

CATEGORY: MALWARE ATTACKS
DESCRIPTION:
Malware attacks involve malicious software designed to infiltrate, damage,
disrupt, or gain unauthorized access to computer systems and networks.
These threats may operate autonomously or be deployed as part of larger
multi-stage attack campaigns.
================================================================================

--------------------------------------------------------------------------------
THREAT NAME: VIRUS
CATEGORY: MALWARE ATTACKS

Definition:
A computer virus is a type of malicious software that attaches itself
to legitimate programs or files and spreads when the infected file is executed.

Attack Mechanism:
Viruses replicate by modifying host files and propagating through
user interaction such as file sharing, downloads, or removable media.

Technical Indicators:
- File modification without authorization
- Unexpected executable behavior
- Increased system instability
- Unauthorized registry changes

Common Payloads:
- File corruption
- Data deletion
- System slowdown
- Boot sector modification

Detection Methods:
- Signature-based antivirus scanning
- Heuristic analysis
- Behavioral monitoring
- File integrity monitoring (FIM)

Severity Factors:
- Propagation speed
- Targeted file types
- Privilege level of execution
- Payload destructiveness

Risk Level Logic:
Risk increases when viruses infect critical system files
or propagate within enterprise networks.

MITRE ATT&CK Mapping:
- Execution
- Persistence
- Defense Evasion
- Impact

Real-World Impact:
Viruses historically caused large-scale system disruptions,
data corruption incidents, and financial losses.

Keywords:
file infection, self-replication, executable malware,
file corruption, host-based infection
--------------------------------------------------------------------------------

Severity Factors:

High risk in flat networks with unpatched services.

CATEGORY: WEB APPLICATION ATTACKS
DESCRIPTION:
Web application attacks target vulnerabilities in web-based systems

THREAT NAME: SQL INJECTION
CATEGORY: WEB APPLICATION ATTACKS

Definition:
SQL Injection is a web attack that injects malicious SQL queries
into input fields to manipulate backend databases.

Attack Mechanism:
Attackers insert crafted SQL statements into URL parameters,
forms, or cookies. If the application fails to sanitize input,
the malicious query is executed by the database server.

Technical Indicators:
- Suspicious URL parameters containing SQL syntax
- Database error messages in responses
- Unusual query behavior
- Authentication bypass patterns

Common Payloads:
- ' OR 1=1 --
- UNION SELECT statements
- Database enumeration queries
- Data extraction commands

Detection Methods:
- Input validation
- Prepared statements
- Web Application Firewall (WAF)
- Log analysis

Severity Factors:
- Database privilege level
- Data sensitivity
- Ability to modify or delete records

Risk Level Logic:
Critical risk if backend database access is achieved.

MITRE ATT&CK Mapping:
- Initial Access
- Credential Access
- Collection
- Impact

Real-World Impact:
SQL Injection has led to massive data breaches,
exposing millions of user records worldwide.

Keywords:
database injection, SQL payload,
authentication bypass, query manipulation
--------------------------------------------------------------------------------

Definition:
CSRF is an attack that tricks authenticated users into performing
unintended actions on a web application.

Attack Mechanism:
The attacker crafts a malicious request and forces the victim’s browser
to send it automatically while the victim is authenticated.

Technical Indicators:
- Unauthorized state-changing requests
- Missing CSRF tokens
- Suspicious form submissions
- Requests triggered without user interaction

Common Payloads:
- Hidden form submissions
- Forged POST requests
- Automatic image-based GET requests

Detection Methods:
- CSRF tokens
- SameSite cookie attributes
- Referer validation
- Multi-factor authentication

Severity Factors:
- Privilege level of victim
- Ability to modify sensitive data
- Lack of token validation

Risk Level Logic:
High risk if attackers can modify accounts or financial data.

MITRE ATT&CK Mapping:
- Initial Access
- Impact

Real-World Impact:
CSRF has been used to change passwords,
transfer funds, and alter account settings.

Keywords:
forged request, session abuse,
unauthorized action, token validation bypass
